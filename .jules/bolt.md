## 2024-03-24 - Array Map+Find Optimization\n**Learning:** The array.map().find(Boolean) pattern eagerly allocates arrays and evaluates map functions unnecessarily when we only need the first truthy match. A simple for...of loop with early return is significantly more efficient and avoids intermediate array allocations.\n**Action:** Replaced map.find with early-return for loops in hot paths like session gateway and usage auth resolution to reduce memory pressure and evaluation overhead.
