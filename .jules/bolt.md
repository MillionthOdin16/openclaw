## 2024-05-18 - Caching normalized messages in `groupMessages` and `buildChatItems`
**Learning:** `ui/src/ui/views/chat.ts` calls `normalizeMessage(msg)` twice for every message in history during the render cycle: once in `buildChatItems` and once in `groupMessages`. The `normalizeMessage` function is not particularly cheap because it clones/maps arrays and does string manipulation/metadata stripping. Since `chat.ts` re-renders frequently (e.g. on every keystroke in the textarea because `props.draft` changes, or whenever streaming occurs), running this for up to 200 messages repeatedly is a performance bottleneck.
**Action:** We can introduce a `WeakMap` cache for `normalizeMessage(message: unknown)` inside `message-normalizer.ts` so that identical message references return the cached normalized result instantly. This avoids duplicate work in `buildChatItems` and `groupMessages` and across render cycles, improving chat re-render performance significantly.
