## 2026-08-21 - Uninstall Command Pattern
**Defect Pattern:** The `openclaw uninstall` command aggressively deletes workspace directories if the `workspace` component is selected. Since workspace directories often overlap with local project folders, git repos, or system locations that existed before the user assigned an OpenClaw agent to them, this causes critical, irrecoverable data loss of user files during uninstall.
**Local Impact:** This defect is present in our local `src/commands/uninstall.ts` where `removeWorkspaceDirs` and `removePath` are called. This results in the same data loss bug if a user runs uninstall and selects the `workspace` component or uses `--all`.
**Review Strategy:** `src/commands/uninstall.ts`, `src/commands/cleanup-utils.ts`, and `src/commands/cleanup-plan.ts` need to be checked for proper handling of workspace cleanup. Workspace directories should likely never be deleted by the uninstaller unless explicitly confirmed by path, or better yet, should just be skipped by default.
