## 2024-05-14 - Double-encoded Path Traversal bypass in UI Assets
**Vulnerability:** The `isSafeRelativePath` function used to protect the Control UI asset server checked for path traversal components (`../`) without iteratively decoding the input. Attackers could bypass this check by using URL-encoded equivalents like `%2e%2e%2f` or double-encoded equivalents like `%252e%252e%252f`.
**Learning:** Checking for literal string matches of `../` is insufficient when the underlying path resolution or input parsing implicitly decodes paths. Node.js `path.resolve` or file operations might not decode paths automatically, but if a path comes from a URL and is partially decoded or accessed directly, malicious segments can be smuggled through if not canonicalized fully first.
**Prevention:** Always iteratively decode paths fully (until they stop changing) using `decodeURIComponent` before running security normalization checks (`path.normalize`) and determining if a path escapes its intended root.
