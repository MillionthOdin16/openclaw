## 2024-05-18 - Missing XSS protection when rendering Markdown HTML blocks in A2UI
**Vulnerability:** A2UI renderers (Angular and Lit) have a vulnerability when rendering Markdown blocks tagged with `html`. Specifically, they construct an `iframe` element and assign `iframe.srcdoc = str`, but then mistakenly return `iframe.innerHTML`. `iframe.innerHTML` evaluates to an empty string because an iframe doesn't have child nodes in the way it's constructed here, so no HTML is actually rendered. If it actually returned the iframe, it would be an iframe with the content inside. However, even if it returned the iframe properly, another component `unescapeNodeText` (and `escapeNodeText`) use `frag.innerHTML` after inserting text into a `<textarea>` or `<div>`. For `<textarea>`, this correctly escapes content but does not serialize it safely. We should fix the `iframe.outerHTML` error to actually render the iframe.
**Learning:** `iframe.innerHTML` is empty. You need to use `iframe.outerHTML` to return the serialized string of an element to be inserted elsewhere.
**Prevention:** Always test the generated HTML structure when dynamically creating elements for string serialization. Use `outerHTML` when you need the complete tag, including attributes.
